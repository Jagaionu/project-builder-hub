# Accounts, Logins & Passwords

## What are the user roles?

- **Super admin** — platform operator; manages all companies from the Admin console.
- **Company admin** — manages one company; has access to every tab including Team, Events, and Billing.
- **Member** — a regular user; uses Live Map, Dispatch, Drivers, Warehouses, Alerts, and the AI assistant. Members cannot see Events, Billing, or Team, and cannot create users.

## If I am not an admin, can I create a new user?

No. Only the company admin (or the platform super admin) can create user profiles. Members cannot create users or reset other people's passwords. The "Team" tab where profiles are created is only visible to the admin.

## How do I add a user / create a profile? (admin)

Open the **Team** tab (admin only), type the person's name under "Add a profile", and click **Add profile**. The app generates their login and a one-time password — give those to the person. They set their own password on first sign-in.

## How do I change my password?

- If you were just created and have a temporary password, you'll be asked to **set your own password on first login** — enter a new password to finish setup.
- To reset someone's password, an admin opens the **Team** tab, finds the person, and clicks **Reset** to issue a new one-time password.
- The company admin's own password is managed by the super admin (Reset/Regenerate in the Admin console).

## How does logging in work?

- The **company admin** signs in at the login page with the admin login (shown in the Admin console) and password.
- **Members** sign in on a shared device by tapping their name on the profile picker (the lock screen) and entering their password — they don't type an email.
- Once a device has member profiles, everyone (including the admin) picks their profile on the lock screen.

## I forgot or lost my password

Ask your company admin to **Reset** your profile in the Team tab; they'll give you a new one-time password and you'll set a new personal one on next login.
